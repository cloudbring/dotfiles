# 2026-10-21: Switch from zsh to bash

zsh trips up LLM agents driving the terminal, and nothing in it was essential.

- Removed `.zshrc`, `.zprofile`, `.zlogin` and `~/.config/zsh/`.
- Added `.bash_profile` (environment) and `.bashrc` + `~/.config/bash/*.sh`
  (interactive). Agent shells skip the cat/ls/cd replacements and the prompt.
- mise (shims, no prompt hook) replaces the lazy-loaded nvm, pyenv and SDKMAN wrappers.
- Colors: vivid LS_COLORS, bat man pages, delta for git, starship runtime modules.
- Brewfile moved into a chezmoi `run_onchange_` script.
- From the old `config` repo: `github.user` and the history/shopt settings.
  Dropped: Pearl, Atom, EverVim, IntelliJ 2018, Mindshow SSH aliases, `DOCKER_HOST`.
- Dropped the custom `timeout` function (it shadowed coreutils `timeout`).
- Startup tuned to ~26 ms interactive, ~7 ms for agents (was ~140 ms in the first
  bash draft): inlined `brew shellenv`, cached tool inits, lazy completions,
  no per-prompt subprocesses besides starship. See README › Speed.
- Secrets moved to 1Password: SSH keys via the 1Password SSH agent, SSH commit
  signing via op-ssh-sign, API keys as `op://` references used by `opx` (op run).
  chezmoi no longer reads 1Password, and no secret is written to disk or exported.
- Removed the `upstream` remote (offlinehacker/dotfiles); its history is not ours.
