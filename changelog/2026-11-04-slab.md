# 2026-11-04: Bring slab onto the bash dotfiles

slab (this Mac) still ran the zsh setup and an old chezmoi checkout. Changes
pulled into the repo so it can apply the bash setup without losing anything:

- Newer local nvim config (2026-03-07): minuet-ai (Gemini) replaces copilot,
  lazy telescope keymaps, noice routes, plus the missing `lazy.lua`,
  `autocmds.lua`, `stylua.toml` and `lazy-lock.json`. Kept the corrected
  1Password field ID for vim-chatgpt.
- opencode `AGENTS.md`: the current shared agent rules.
- New: `.tmux.conf`, `~/.config/git/ignore`, jj and Zed settings,
  `~/bin/op-agent` and `~/bin/claude-proxy` (both read secrets at run time).
- `.bash_profile`: PATH entries that tool installers had appended to zsh/bash rc
  files (cargo, Docker, turso, SDKMAN java, Antigravity, MiniMax, oMLX), each
  skipped if absent; sources an untracked `~/.bash_profile.local`.
- `~/.ssh/config`: includes untracked `fleet.conf` and `config.local` first, so
  internal hosts stay out of the public repo and fleet keys win where present.
- `.gitconfig`: fleet machines sign with the on-disk fleet key (`ssh-keygen`)
  instead of 1Password; HTTPS GitHub remotes use `gh auth git-credential`.
- Brewfile: gh, tmux, jj.
- bash `pi` wrapper (runs Pi under Bun), ported from zsh.

Not carried over: the zsh `claude-proxy` function (same as `~/bin/claude-proxy`),
the `timeout` override, Lazyman, conda (no longer installed), and the global
llvm/icu4c PATH and compiler flags (put them in `~/.bash_profile.local` if needed).
